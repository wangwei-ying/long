# 江山筑城

一款原创的古代中国题材城市营造网页游戏（demo）。three.js 渲染，自写着色器，无需构建即可运行。

## 运行

```bash
npm install          # 只为打包工具 esbuild；运行游戏本身不需要
npm run dev          # 本地起服务：http://localhost:5173
npm run build        # 打成单文件 dist/index.html（three.js 走 CDN）
```

ES 模块不能从 `file://` 加载，所以要用本地服务打开。

## 玩法

- 粮食链：农田 → 推车 → 粮仓 → 挑夫 → 集市 → 货郎沿街 → 民居
- 货物链：桑园 → 蚕茧 → 丝坊 → 丝绸；河边陶窑 → 陶器；两者入货栈，再由集市挑夫取走、货郎卖出
- 民居升级：宅地 → 茅屋 →（水、粮）瓦舍 →（祭祀、风水 2.5）宅院 →（陶器、茶楼娱乐、风水 3.5）府邸 →（丝绸、风水 4.5）大宅
- 劳力：各级民居按比例出工（茅屋瓦舍 50%，宅院 42%，府邸 30%，大宅 20%），按优先级分到作坊（粮食 > 集市 > 手工 > 祠庙茶楼），每座建筑按在岗比例产出；工位上能看到工人干活
- 收支：月入赋税 + 市税（货郎卖货），月出工钱 + 维护；顶栏「账簿」查看收支、货物产销与劳力去向
- 可见的物流：推车按货物显示麻袋 / 蚕茧 / 陶罐 / 丝绸，挑夫与货郎的担子有货才满；粮仓、货栈、集市、窑口的货堆随库存增减；建筑头顶的印章标出缺工、断料、满仓、无路，民居标出饥、渴、衰、升
- 存档：每月自动存到本浏览器，顶栏可手动存档，开场可继续或另起新城
- 风水：靠山、临水、园林、祠庙为吉；粮仓、集市、农田为凶
- 风水 = 形势 + 五行：形势看山水、园林、祠庙（加分）与粮仓、陶窑、作坊（扣分）；五行看民居坐向（朝南火、东木、西金、北水）与周边主导五行的生克（生 +1、同 +0.5、泄耗 −0.3、克 −1）。顶栏「风水」「五行」两个图层；选中建筑放到地图上会预览它让周边民居风水升降多少、几户因此升级或退级
- 新手教程：开场「新手教程」一步步带着做，地图上有箭头标出建议位置；顶栏「说明」是分页手册；点左上角目标会高亮还差条件的民居
- 关卡：三阶段——营城之志（人口 150、3 座宅院、祠庙）→ 兴业之志（陶器月产 25、丝绸月产 16、6 座府邸、水龙局与营缮所）→ 繁华之志（人口 600、5 座大宅、商队收入 1500、铜钱 10000）。第十二年腊月前完成即通关；国库亏空超过 1000 文连续 4 个月或到期未完成即失败
- 灾害：建筑积累火险（陶窑最高），满了或运气差就起火，会蔓延到邻居，一个半月无人扑救即烧成废墟；水龙局的巡更人清火险、水龙队赶去救火。建筑年久失修会倒塌，营缮所的匠人修缮。汛年四月预告、六月河边三格被淹，河堤保护周围三格。废墟用拆除清理
- 商队：建商栈后，商队每三个月从西边官道来；「商队」面板设定每种货出口（至少留多少）或进口（补足到多少），进口的货由推车送进仓库
- 流向图层（G）：各条产业链从产地到仓库、集市、民居的流动弧线，卡住的环节标红闪烁，并列出原因
- AI 自动经营：开场「观看 AI 自动经营」，随时点顶栏按钮接手
- 画面：顶栏“画意”切换国画风格与写实渲染，“描边”开关勾线

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/config.js` | 建筑、等级、风水、平衡数值 |
| `src/world.js` | 地形生成（河流、山脉、树林）、格子数据、道路 BFS 寻路、水源与风水计算 |
| `src/sim.js` | 经济模拟、劳力、步行者（移民/推车/挑夫/货郎/祭司）、民居升降级 |
| `src/roofs.js` | 参数化屋顶：悬山 / 庑殿 / 腰檐 / 攒尖，生起、翼角起翘出翘，屋脊、鸱吻、走兽 |
| `src/trees.js` | 国画树：程序化枝干 + 着色器叶团（点叶、松针、柳、竹），炊烟 |
| `src/models.js` | 程序化建模：曲面屋顶、斗拱彩画、窗棂、栏杆石狮、三级民居、各类建筑、步行者 |
| `src/materials.js` | 程序化材质：往标准材质注入瓦垄、草茎、木纹、夯土、砖缝、石板、彩画、窗棂的纹样与凹凸 |
| `src/post.js` | 后期：半分辨率 SSAO、笔触勾线、颜料设色、地图外渐入水墨与留白、宣纸纹理、辉光 |
| `src/render.js` | 地形着色器（青绿设色/道路/田垄/图层/放置预览）、河水着色器（水纹）、天空（宣纸、朱砂日、水墨远山）与昼夜、实例化树木 |
| `src/camera.js` | 相机平移、缩放、旋转 |
| `src/ui.js` / `src/main.js` | 界面与输入 |
| `src/bot.js` | 自动玩家：只用玩家能用的指令，按看得到的信息决策（验收与演示共用） |
| `src/flow.js` | 产业链流向图层 |
| `src/scenario.js` | 关卡开局村落 |
| `src/tutorial.js` | 新手引导教程 |
| `src/fsview.js` | 风水预览：放下建筑前算出对周边民居的影响 |
| `tools/build.mjs` | 打包成单页 |
| `tools/autoplay.mjs` | 自动验收：自动玩家从开局玩到结局，打印时间线与结算 |
| `tools/hazards.mjs` | 灾害与商队专项验收：逐项制造情境检查每个分支 |

## 验收

```bash
node tools/autoplay.mjs 1      # 种子 1：完整玩一局（约 10 秒）
node tools/hazards.mjs         # 31 项灾害、商队、失败条件、存档、五行检查
```
